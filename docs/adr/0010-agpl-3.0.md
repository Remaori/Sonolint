# 0010. Sonolint is licensed under AGPL-3.0

Status: accepted (2026-11-15)

**Decision.** Sonolint is released under the GNU AGPL v3, like Heft.

**Alternative rejected.** MIT.

**Why.** JUCE is available under the AGPLv3 or a commercial licence, and using it
under the open one requires Sonolint to be AGPL too. The VST 3 SDK has been MIT since
version 3.8, so it adds no restriction. Hosting a third-party plugin with Sonolint
doesn't change that plugin's licence.
